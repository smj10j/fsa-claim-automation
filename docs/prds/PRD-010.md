# PRD-010: Export, Reporting & Tax Documentation

**Status**: `draft`
**Priority**: P2
**Effort**: M (3–5 days)
**Dependencies**: PRD-006
**Last updated**: 2026-03-18

---

## Problem

FSA contributions are made pre-tax, and while FSA reimbursements are generally tax-free, users need to keep records of their claims for personal accounting and, in case of an audit, to demonstrate the expenses were eligible medical expenses. Currently users have no way to export their claim history in a usable format. This is also a key feature for power users and small business owners who want to understand their healthcare spending patterns.

---

## Goals

1. Export claim history in common formats (CSV, PDF) for record-keeping and tax purposes.
2. Generate a year-end summary report suitable for personal finance tools.
3. Provide spending analytics that help users make smarter FSA elections in future years.
4. Build a feature set that power users will pay for.

## Non-Goals

- Tax filing integration (TurboTax, H&R Block, etc.) — future feature
- Automated IRS form generation
- Cloud backup or sync (local-first; export is the sync mechanism)

| # | As a… | I want to… | So that… |
|---|-------|-----------|---------|
| 1 | User | Export all my claims to a CSV file | I can import them into my expense tracking spreadsheet |

## Functional Requirements

### FR-1: CSV Export
- Export all claims (or filtered subset) as a CSV file with columns:
  - Claim ID, Submission Date, Merchant, Service Date, Category, Items, Claimed Amount, Approved Amount, Status, Denial Reason
- Triggered from History tab "Export" dropdown → "Download CSV"
- Filename: `fsa-claims-{year}.csv`
- Open date range picker to export specific benefit year.

### FR-2: PDF Year-End Summary Report
- Generate a single-page (or multi-page) PDF containing:
  - Header: "FSA Claim Summary — Benefit Year [Year]"
  - Summary table: Total Elected | Total Claimed | Total Approved | Remaining Balance
  - Itemized claims table (same columns as CSV)
  - Disclaimer: "This report is for personal record-keeping only. Consult a tax professional for advice."
- Use `@react-pdf/renderer` or browser `window.print()` with a print-optimized CSS.
- Triggered from: History tab "Export" → "Download PDF Summary"

### FR-3: Invoice ZIP Export
- Export all captured invoice images as a ZIP file.
- ZIP structure:
  ```
  fsa-invoices-{year}/
    {orderId}-{date}-{merchant}.png
    ...
  ```
- Use `JSZip` library (browser-compatible).
- Triggered from History tab "Export" → "Download All Invoices (.zip)"
- Show progress for large exports (many invoices).

### FR-4: Spending Analytics Dashboard
- New "Analytics" sub-tab in History tab.
- Charts (using lightweight chart library or hand-rolled SVG):
  - **Monthly spending bar chart**: Approved claims by month
  - **Category breakdown pie/donut**: OTC drugs, medical equipment, first aid, etc.
  - **Cumulative spend line chart**: Running total vs. election over the year
- Metric callouts:
  - "Average claim amount: $42"
  - "Most claimed category: OTC Drugs (47%)"
  - "Peak spending month: December"

### FR-5: Next-Year Election Estimator
- Based on current year's approved claims, suggest next year's FSA election:
  - "Based on your claims this year ($1,247), consider electing at least $1,300 for next year."
- Tax savings estimate:
  - "At a 22% tax bracket, a $1,500 FSA election saves you ~$330/year in taxes."
  - User inputs their approximate tax bracket (not required; defaults to 22%).

### FR-6: Data Portability & Backup
- "Export All Data" button exports the entire extension state as a JSON file:
  - Settings, all claims, eligibility overrides, user preferences
  - Does NOT include invoice images (too large; export separately via FR-3)
- "Import Data" button restores from a previously exported JSON.
  - Useful for migrating to a new device or Chrome profile.
- Data format is documented and versioned for forward compatibility.

### FR-7: Audit-Ready Package
- "Generate Audit Package" creates a ZIP containing:
  - PDF summary report (FR-2)
  - All invoices (FR-3 format)
  - CSV claims export (FR-1)
- One click to prepare everything an FSA administrator might ask for.
- Framed as "in case your employer audits your FSA claims."

## Technical Notes

- PDF generation in Chrome extensions is tricky — `window.print()` with print CSS is simplest; `@react-pdf/renderer` is more flexible but adds ~200KB to bundle.
- `JSZip` is well-supported and small (~100KB gzipped).
- Analytics charts: use `recharts` (React-native) or plain SVG — avoid heavy D3 or Chart.js for bundle size.
- Invoice ZIPs can be large (50 invoices × 300KB = ~15MB) — use streaming download with `URL.createObjectURL`.
- All export operations are purely local — no network calls, no third-party services.
